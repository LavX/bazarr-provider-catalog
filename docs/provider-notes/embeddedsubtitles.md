# Embedded Subtitles Provider Notes

- Legacy source: `/home/lavx/bazarr/custom_libs/subliminal_patch/providers/embeddedsubtitles.py`.
- Catalog id: `embeddedsubtitles`, reusing the built-in provider id so a trusted catalog install overwrites the built-in in place (no duplicate provider).
- Provider type: local media extractor, not a web subtitle source.
- Catalog behavior: inspects local media files with `ffprobe`, exposes allowed embedded text subtitle streams, and extracts the selected stream with `ffmpeg`.
- External requirements: Bazarr+ worker must be able to read the media path and execute configured `ffprobe` and `ffmpeg` binaries.
- Supported codecs: `ass`, `subrip`, `webvtt`, and `mov_text`.
- Download flow: generated subtitle bytes from the local media container.
- Regional variants: the manifest declares `por-BR`, `spa-MX` and `zho-TW` alongside the base codes so the pool asks for them (`spa-MX` is Bazarr's Latin American Spanish variant). Language tags carrying a modeled subtag map at the tag level (`pt-BR` to Brazilian Portuguese; `es-419`, `es-MX` and `es-AR`, the subtags Bazarr itself files under its Latino variant, to Latin American Spanish; `zh-Hant` and `zh-TW` to Traditional Chinese). For Matroska tracks remuxed with a legacy `language` element (mkvmerge maps `pt-BR` to `por`), a bare language tag may additionally be refined from the track title: whole-word markers and word-start stems (`pt-br`, `pob`, `brazil*`, `bresil*` for por; `es-mx`, `mx`, `lat`, `mexic*`, `latin*`, `argent*` for spa; `zh-tw`, `cht`, `tc`, `tradi*`, `taiwan*`, `繁體` for zho; the full list is `TITLE_REGION_MARKERS` in the provider), with accents folded before matching and words bounded so `Pobre` or `Platino` never match. The por and spa markers start from the upstream provider's vendored fese; the zho markers start from the Traditional Chinese custom language Bazarr matches on filenames; both sets extend to translated region names and the CJK spellings of Traditional, and a `繁` marker directly after a Simplified character never matches, so mixed-script labels like `简繁中文` stay plain. A tag carrying any subtag is an explicit statement and wins over the title, modeled region or not. A title-classified regional track no longer satisfies a plain-language profile: add the regional variant to the profile.
- Unknown-language fallback results are suppressed when an explicit stream has the same language and forced/hearing-impaired disposition. A fallback with a different disposition remains available.
